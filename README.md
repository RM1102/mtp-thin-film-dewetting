# Thin-film dewetting: results pages

Results pages that accompany the M.Tech thesis report (CLD 880, Department of Chemical Engineering, IIT Delhi), "A physics-informed neural network for spinodal dewetting of nanometre-thin liquid films", by Rahul Arvind Masand, supervised by Prof. Jayati Sarkar (17 November 2026).

Open the site: https://rm1102.github.io/mtp-thin-film-dewetting/

| Page | What it shows |
|---|---|
| `animations/film_2d.html` | Thin film, side view: from a nearly flat start until the liquid gathers into a drop |
| `animations/film_3d.html` | Thin film in 3D: the whole film until it first reaches the floor, and one drop forming (WebGL 2) |
| `animations/fd_answer_key_2d.html` | The 2D finite-difference answer key, tau 0 to 20, used to score the 2D PINN |

Each page is one self-contained HTML file (no external resources). The code and the raw data stay in the private project repository; this repository holds only these pages.
